# ODAK Audio - E-Ticaret ve Müşteri Deneyimi Platformu

Bu proje, temel bir şablon mimarisi üzerine modern web teknolojileri kullanılarak sıfırdan geliştirilmiş, kullanıcı dostu ve dinamik bir e-ticaret arayüzüdür.

## 🚀 Projeye Eklediğim Özellikler ve Geliştirmeler
- **Dinamik Sepet Yönetimi (LocalStorage):** JavaScript kullanılarak sayfa yenilendiğinde bile kaybolmayan ürün ekleme, çıkarma ve dinamik sepet badge güncellemeleri yapıldı.
- **Canlı Arama Motoru (Search Modal):** Kullanıcıların ürünleri hızlıca bulabilmesi için JS tabanlı anlık arama entegrasyonu kodlandı.
- **Akıllı Asistan (Chatbot):** Müşteri deneyimini artırmak için etkileşimli, açılıp kapanabilen asistan arayüzü (`chatbot.js`) projeye dahil edildi.
- **Modern CSS Mimarisi:** Şablonun üzerine eklenen tüm stiller profesyonel bir yapıda tutulmak için `base`, `components`, `layout` ve `pages` olarak modüllere ayrıldı.
- **Eksiksiz Alt Sayfalar:** Sepet (`cart.html`), katalog, 404 Hata, Garanti, Gizlilik ve İletişim gibi tüm e-ticaret gereksinimleri tasarlanıp birbirine bağlandı.

## 🛠️ Kullanılan Teknolojiler
- **HTML5 & CSS3** (Özel Modüler Mimari)
- *** JavaScript*** (DOM Manipülasyonu, localStorage, Event Listeners)
- **Git & GitHub** (Versiyon Kontrolü ve GitHub Pages Canlı Yayın)
